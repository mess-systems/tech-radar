## What it is

Open-source tool to run Windows apps on Linux (MIT). Official site: [winboat.app](https://www.winboat.app/).

## Why mess.systems uses it

Windows-only apps on Linux devices.

## Alternatives considered

Wine, a full VM. Chosen for integration with the desktop.
