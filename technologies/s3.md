## What it is

The Amazon S3 object storage API, implemented by many cloud and self-hosted object stores. Official site: [docs.aws.amazon.com/AmazonS3/latest/API/Welcome.html](https://docs.aws.amazon.com/AmazonS3/latest/API/Welcome.html).

## Why mess.systems uses it

The object forms name buckets `<plane>-<domain>-<capability>-<env>`, and S3 bucket rules are one source of the character rules. It is the interface of the `objects` capability.

## Alternatives considered

Provider-specific object APIs. Chosen because it is the most widely implemented object storage interface.
