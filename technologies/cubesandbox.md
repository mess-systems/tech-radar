## What it is

Open-source MicroVM sandbox for AI agents on KVM, E2B-compatible API. Official site: [cubesandbox.com](https://cubesandbox.com/).

## Why mess.systems uses it

Carries the `sandbox` capability for agent code execution.

## Alternatives considered

E2B, gVisor containers. Chosen for hardware isolation and self-hosting.
