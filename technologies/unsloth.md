Open-source library for fast LLM fine-tuning (Apache-2.0). Official site: [unsloth.ai](https://unsloth.ai/).

## Why mess.systems uses it

Fine-tuning of open models.

## Alternatives considered

Plain Hugging Face training. Chosen for speed and memory use.
