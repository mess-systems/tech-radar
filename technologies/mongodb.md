## What it is

Document database. The Community Server is under the Server Side Public License (SSPL), which is not an OSI-approved open-source license. Official site: [www.mongodb.com](https://www.mongodb.com/).

## Why mess.systems uses it

It is the example for the `docstore` capability in the worked encodings (`docstore.data.platform`) and in the database roles.

## Alternatives considered

Other document stores, or JSON columns in PostgreSQL. Trial because the standard names it as an illustration.

## Where it applies

- [Worked encodings](https://github.com/mess-systems/naming-standard/blob/main/01-naming-conventions.md#11-worked-encodings)
- [Database roles](https://github.com/mess-systems/naming-standard/blob/main/04-identity-conventions.md#11-database-roles)

## Review trigger

After it has carried the `docstore` capability in a limited scope: promote to Adopt or move to Hold. Earlier on a license change.
