## What it is

Code quality and static analysis platform; the Community Build is open source (LGPL-3.0). Official site: [sonarsource.com/products/sonarqube](https://www.sonarsource.com/products/sonarqube/).

## Why mess.systems uses it

Quality gate for code in CI, next to Opengrep for security rules.

## Alternatives considered

Opengrep alone, CodeQL. Chosen for quality gates and broad language coverage.
