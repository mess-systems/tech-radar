## What it is

Lightweight self-hosted git forge (MIT) with pull requests, issues, packages, and Actions-compatible CI. Official site: [about.gitea.com](https://about.gitea.com/).

## Why mess.systems uses it

It is the example product for the `git` capability in the worked encodings (`git.sdlc.eng`). The standard uses it to show that the FQDN carries the capability (`git`), never the product.

## Alternatives considered

Other git forges. Trial because the standard names it as an illustration.
