## What it is

Open-source framework for stateful agent graphs (MIT). Official site: [langchain.com/langgraph](https://www.langchain.com/langgraph).

## Why mess.systems uses it

Default framework for agents in code.

## Alternatives considered

Other agent frameworks. Chosen for explicit state and control.
